# صفحة "الموقع تحت الإنشاء": مدارس دار الفرسان الأهلية

صفحة ثابتة (HTML/CSS + سطر JavaScript واحد)، ثنائية اللغة (عربي/إنجليزي)، بلا قاعدة بيانات ولا PHP ولا طلبات خارجية.
هي أول تجربة نشر لمشروع الموقع الجديد، وتُحذف أو تُستبدل عند إطلاق الموقع الكامل.

## الملفات

```
idar-coming-soon/
├── index.html
├── logo-white-520.png        الشعار الرئيسي (نسخة بيضاء رسمية)
├── logo-diploma-white.png    شعار قسم الدبلوما (أبيض أحادي)
├── logo-sp-edu-white.png     شعار قسم التربية الخاصة (أبيض أحادي)
└── favicon-180.png           أيقونة التبويب
```

**بنية مسطحة بلا مجلدات:** كل الملفات الخمسة في مستوى واحد، والكود يقرأ الصور بأسمائها مباشرة. يجب رفعها كلها إلى المجلد نفسه (بجانب `index.html`).

## معاينة محلية

افتح `index.html` في المتصفح مباشرة، أو من مجلد المشروع:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## النشر على الاستضافة (Hostinger): خطوات مقترحة

> الخطوات مبنية على معرفة عامة بالاستضافة المشتركة، ولم تُختبر على حسابكم. تحقق من كل خطوة في hPanel.

### 0) قبل أي شيء
1. **نسخة احتياطية كاملة** (ملفات وقاعدة بيانات) من hPanel، ونزّلها خارج الاستضافة.
2. لا تحذف ملفات WordPress الحالية في هذه المرحلة.

### 1) نشر تجريبي على نطاق فرعي (موصى به)
1. أنشئ نطاقاً فرعياً (مثل `soon.daralforsan.edu.sa`) وفعّل SSL له. تحقق أن النطاق `.edu.sa` يسمح بذلك ومن أين تُدار سجلات DNS.
2. ارفع **الملفات الخمسة** (`index.html` والصور الأربع) إلى مجلد ذلك النطاق الفرعي عبر File Manager أو FTP/SFTP.
3. افتح الرابط من الجوال والحاسب وراجع ما يلي.

### 2) قائمة التحقق قبل الاعتماد
- [ ] الشعارات الثلاثة تظهر ولا توجد صور مكسورة
- [ ] الاتجاه RTL سليم والنص الإنجليزي يظهر LTR
- [ ] أرقام الاتصال صحيحة (920001684 و0537311684 و0531611684 و0573561112)
- [ ] روابط التواصل الاجتماعي الستة تفتح الحسابات الصحيحة (**لم تُفحص بعد**)
- [ ] لا تمرير أفقي على الجوال
- [ ] توهج بطاقات الفروع يعمل عند المرور واللمس
- [ ] الخطوط: **Cairo وTajawal غير مضمَّنتين بعد** (انظر أدناه)

### 2.1) تضمين الخطوط (مطلوب قبل الإطلاق النهائي)
1. نزّل Cairo وTajawal من Google Fonts (ترخيص OFL) بصيغة `woff2`.
2. ضعها في المجلد نفسه (أو في مجلد `fonts/` وعدّل المسار).
3. أضف `@font-face` في `index.html` بالأوزان المعتمدة: Cairo (400/600/700/900) وTajawal (400/500/700/900)، مع `font-display: swap`.
4. تضمين الخطوط محلياً يمنع مشاركة بيانات الزوار مع Google ويحسّن الأداء.

### 3) النشر على النطاق الرئيسي (بعد الاعتماد فقط)
1. خذ نسخة احتياطية جديدة.
2. انقل ملفات WordPress خارج `public_html` أو إلى مجلد أرشيف (لا تتركها مكشوفة)، فملفات PHP القديمة سطح هجوم.
3. ضع الملفات الخمسة في `public_html`.
4. تأكد أن الخادم يخدم `index.html` أولاً (يتوقف على إعداد الاستضافة؛ حذف `index.php` يزيل الاحتمال).
5. اختبر `https://daralforsan.edu.sa` في نافذة خاصة.
6. **خطة الرجوع:** استعد النسخة الاحتياطية إن حدث خلل.

### 4) ما بعد النشر
- الصفحة تحمل `noindex` عمداً. **احذف هذا السطر عند إطلاق الموقع الكامل:**
  ```html
  <meta name="robots" content="noindex, nofollow">
  ```
- تحقق من شهادة SSL وإعادة التوجيه من HTTP إلى HTTPS.
- إضافة Under Construction في WordPress الحالي غير ضرورية بعد استبداله.

## إتاحة الوصول والخصوصية
- رابط "تخطي إلى المحتوى" وتركيز مرئي بلوحة المفاتيح، ويحترم `prefers-reduced-motion`.
- لا تتبع ولا ملفات ارتباط ولا طلبات إلى جهات خارجية.
- التباين مقدّر لا مقاس بأداة WCAG رسمية. يُفحص قبل الاعتماد.
